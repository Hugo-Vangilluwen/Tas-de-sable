\begin{abstract}
    Le modèle du tas de sable permet de décrire de nombreux phénomènes physiques
    tels que les tremblements de terre, les réseaux neuronaux, les tempêtes
    solaires ou le langage naturel. Je me suis intéressé aux structures
    algébriques qui émergent naturellement dans ce modèle. Toutes les
    modélisations finissent toujours effectuer des cycles entre certains tas de
    sable dits récurrents. Je vais donc chercher à les caractériser.
\end{abstract}
